# Sum up 24 November 2026 world news in one image

Entry for the [make.fun](https://make.fun) bounty
`news-image-20261124` — $100, top 50 split.

## What it does

`main.py` (Python 3, standard library only) copies the entry image
`entry.png` (768×1024, 417 KB, within the gate's 1024×1024 and 1 MiB
limits) to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
No network, deterministic output.

## Run

```sh
python3 main.py   # writes entry.png to $MAKEFUN_OUTPUT_DIR or /output
```
